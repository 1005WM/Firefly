# Reference UI

PageTitle, the article list, post header and interactive article outline, the collections page, the moments cover and sidebar styles, the compact friend card, archive tree, photo wall, knowledge graph, and guestbook shell were adapted from [dumplingandcakeblog at c5c5482](https://github.com/tianshihao2003/dumplingandcakeblog/tree/c5c54829ec66de42f3276d127f32b2b4982b97af). The upstream [MIT notice](dumplingandcakeblog-LICENSE.txt) is included here.

The site uses the reference configuration's selected font, LXGW WenKai, from the same ZeoSeven distribution. Posts, bookmark entries, profiles, and images come from Autumn Blog's existing configuration and collections.

The desktop navigation dropdowns and sliding highlight are adapted from the reference's `src/styles/components/dropdown.css` and `src/styles/layout/navbar-new.css`.
